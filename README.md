# ostrails-madmp-technical-docs

The technical reference for the three repositories of the SOCIB maDMP pipeline:
[madmp-core](https://github.com/pstcricq/ostrails-madmp-core), which turns
rules into the packages DS Wizard consumes,
[madmp-dsw](https://github.com/pstcricq/ostrails-madmp-dsw), the deployment
that runs them, and
[madmp-registry](https://github.com/pstcricq/ostrails-madmp-registry), where
the plans land.

One section per repository, and one page per part of it. This site says **how**
each part works and what its contract is. It is a reference, not a narrative.

Published with MkDocs Material at
<https://pstcricq.github.io/ostrails-madmp-technical-docs/>.

## Working on it

```bash
uv sync
uv run mkdocs serve
```

`mkdocs build --strict` is what CI runs, and it fails on a link to a page that
no longer exists. Run it before pushing:

```bash
uv run mkdocs build --strict
```

## Regenerating the screenshots

Every picture under `docs/img/` is a build product, not a file someone once
saved. `scripts/screenshots.py` drives a headless Chromium against a running
DS Wizard and remakes all of them at one viewport, in one command. That is
what keeps them from drifting out of date the way hand-taken screenshots do.

It needs a DSW that has been through the end-to-end run, so that the project,
its answers and its submission are there to photograph.

```bash
uv sync --group dev
uv run playwright install chromium
export DSW_API_URL=http://localhost:3000/wizard-api
export DSW_CLIENT_URL=http://localhost:8080/wizard
export DSW_EMAIL=... DSW_PASSWORD=...
uv run --group dev python scripts/screenshots.py
```

The script signs in through the API and writes the token into the client's
`localStorage`, the same session the client would create for itself. Nothing
is ever typed into the login form.

## Layout

```
docs/
├── index.md                  at a glance, the three repositories
├── core/                     madmp-core, one page per package
├── dsw/                      madmp-dsw, the deployment
├── registry/                 madmp-registry, the file contract
├── annexes/                  the end-to-end run, known limits
├── img/                      screenshots, all regenerated by the script
└── stylesheets/extra.css
scripts/screenshots.py        remakes docs/img/
mkdocs.yml                    the theme, and the nav
```
